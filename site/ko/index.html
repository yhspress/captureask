전체 화면 캡처

Chrome 확인 한 번이 필요합니다.

사용자 보호를 위해 Chrome은 모니터를 선택하고 공유를 누르도록 요구합니다. CaptureAsk가 이 시스템 확인을 건너뛸 수는 없습니다. 공유 후에는 선택한 AI가 열리고 캡처 첨부를 준비합니다.

01

설치

ZIP을 내려받아 압축을 푼 후 Chrome 확장 프로그램 → 개발자 모드 → 압축해제된 확장 프로그램 로드를 사용하세요.

02

AI로 보내기

선택한 AI를 열고 첨부를 시도합니다. 질문을 보내기 전에 이미지 썸네일을 확인하세요. 첨부나 클립보드 복사에 실패하면 CaptureAsk를 다시 열어 마지막 미리보기를 저장하고 직접 업로드하세요.

03

사용자가 제어합니다

사용자가 캡처 버튼을 눌렀을 때만 이미지가 생성됩니다. AI 서비스에 공유하기 전 민감 정보를 확인하세요.

04

도움이 필요하신가요?

민감한 페이지에서 사용하기 전에 설치 및 개인정보 가이드를 읽어 보세요.

내 이미지. 내 결정.

저장 공간이 허용하는 범위에서 캡처는 교체·삭제하거나 브라우저를 닫을 때까지 브라우저 세션 메모리에 보관됩니다. AI 첨부 대기열은 2분 후 사용할 수 없으며 해당 캡처로 연 AI 탭에서만 읽을 수 있습니다. AI를 선택하면 해당 서비스에 이미지 공유를 시도합니다. 권한과 데이터 흐름은 개인정보처리방침에서 확인하세요.

캡처 전에 범위를 선택하세요

현재 탭은 화면에 보이는 웹페이지를 캡처하고 미리보기를 표시합니다. 전체 화면 전송은 Chrome에서 모니터를 선택하고 공유한 뒤 진행합니다. 드래그 캡처 전송은 현재 페이지에서 선택한 사각형 영역을 캡처하고 AI를 엽니다.

첨부 여부를 확인하세요

AI 탭이 열렸다고 이미지 첨부까지 성공한 것은 아닙니다. 먼저 AI에 로그인하고 캡처한 뒤 첨부 미리보기를 확인하세요. 이미지가 없으면 현재 탭으로 캡처해 저장한 파일을 AI의 파일 첨부 버튼으로 올리세요.

확인 가능한 질문을 작성하세요

차트의 제목, 단위, 날짜를 함께 포함하세요. 보이는 사실과 추측을 구분하고 읽을 수 없는 글자는 추측하지 말라고 요청하세요. 답변을 원본과 비교한 뒤 활용하세요.
