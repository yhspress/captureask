궁금한 장면을
더 빠르게 이해하는 법.

CaptureAsk의 모든 기능은 사용자의 클릭으로 시작됩니다. 이미지를 자동으로 업로드하거나 AI 서비스에 자동 전송하지 않습니다.

시작하기

  1. Chrome 웹 스토어에서 CaptureAsk를 설치합니다.
  2. 주소창 오른쪽의 확장 프로그램 메뉴에서 CaptureAsk를 고정합니다.
  3. 아이콘을 클릭해 캡처 메뉴를 열고, 필요한 권한을 허용합니다.

화면 캡처하기

현재 보이는 탭

“보이는 화면 캡처”를 선택하면 현재 Chrome 탭의 표시 영역을 이미지로 만듭니다.

원하는 영역

“영역 선택”을 고른 뒤 드래그해 필요한 부분을 지정합니다. Esc 키를 누르면 언제든 취소할 수 있습니다.

알아두세요

Chrome 확장 프로그램은 보안상 운영체제 전체 화면을 자동 캡처할 수 없습니다. 전체 화면이 필요하면 Chrome의 화면 공유 선택창에서 사용자가 직접 화면 또는 창을 선택해야 합니다.

AI에게 보내기

캡처 후 원하는 AI를 선택합니다. CaptureAsk는 캡처 이미지를 클립보드에 복사하고 선택한 서비스의 공식 웹사이트를 새 탭에서 엽니다.

  1. ChatGPT, Claude, Gemini 또는 Grok을 선택합니다.
  2. 열린 대화창을 클릭합니다.
  3. Ctrl + V(Mac: ⌘ + V)로 이미지를 붙여 넣고 질문을 작성합니다.

AI 서비스의 계정 로그인, 파일 업로드 제한, 데이터 처리 정책은 각 서비스의 정책을 따릅니다.

개인정보 및 권한

CaptureAsk는 화면 캡처 기능을 위해 현재 탭 및 사용자가 선택한 화면에 대한 접근 권한을 요청할 수 있습니다. 캡처 파일은 기본적으로 사용자의 기기에 저장됩니다.

  • 사용자가 “AI에게 보내기”를 선택하기 전에는 외부 AI 서비스로 이미지를 전송하지 않습니다.
  • 민감 정보, 비밀번호, 금융 정보가 포함된 화면은 캡처·공유 전에 반드시 확인하세요.
  • 설치한 확장 프로그램의 권한은 Chrome 확장 관리 페이지에서 언제든 확인하거나 철회할 수 있습니다.

문제 해결

캡처 메뉴가 열리지 않아요.
페이지를 새로고침하고 확장 프로그램이 활성화되어 있는지 확인하세요. 시크릿 모드에서는 별도 허용이 필요합니다.
AI 입력창에 붙여넣기가 안 돼요.
AI 서비스 탭을 먼저 클릭한 후 Ctrl + V를 누르세요. 해당 서비스가 이미지 업로드를 지원하는지와 로그인 상태도 확인하세요.
다운로드 파일을 찾을 수 없어요.
Chrome 설정의 다운로드 위치를 확인하세요. 브라우저가 “매번 저장 위치 확인”으로 설정되어 있으면 위치 선택창이 표시됩니다.
